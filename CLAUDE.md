# Каркас Комфорт — правила работы над проектом

## Публикация демо после каждой правки

Заказчик смотрит демо-версию на временном адресе
**https://dkaratsapov-web.github.io/karkas_comfort/** — поэтому **каждая правка
сайта заканчивается публикацией демо**, а не просто коммитом.

```bash
npm run build && npm run verify  # собрать и проверить
git add -A && git commit -m "…"  # закоммитить
npm run publish:demo             # опубликовать демо
```

`npm run verify` поднимает собранный сайт на свободном порту и гоняет
две проверки: сценарии (`tools/check.mjs`) и визуальный контроль
(`tools/visual.mjs`). Визуальный проходит все страницы из sitemap на
четырёх ширинах и ловит то, что не видно в разметке: наложение текста,
текст шире своей ячейки, вылет за контейнер, горизонтальную прокрутку,
не загрузившиеся картинки, мелкие цели на телефоне и ошибки JS.
`npm run publish:demo` сам вызывает `verify` и не публикует, если
проверки не прошли.

`npm run publish:demo` пушит рабочую ветку и перематывает на неё ветку
по умолчанию. Второй шаг обязателен: окружение `github-pages` пускает
на публикацию только ветку по умолчанию, поэтому пуша в рабочую ветку мало —
демо просто не обновится. Перемотка идёт без принудительного пуша: если
в ветке публикации появятся чужие коммиты, GitHub откажет, и их нужно
сначала забрать (`git fetch origin && git merge origin/<ветка>`).

Сборка занимает 1–2 минуты, ход виден во вкладке Actions → «Preview site».
Проверить результат из этой среды нельзя: обращения к github.io блокирует
политика сети. Подтверждение публикации берём из логов workflow, а заказчику
честно говорим, что страницу глазами не видели.

## Что важно не сломать

- **Правим `src/`, `assets/`, `server/`, `tools/`.** Папка `dist/` — результат
  сборки, руками её не трогаем; страницы проектов `dist/proekty/<код>.html`
  генерируются из `src/data/projects.json`.
- **Данные вместо кода.** Цены, фотографии, сроки, отзывы и номера счётчиков
  живут в `src/data/` — см. `src/data/README.md`. Заменить заглушки на реальные
  материалы должно получаться без правки вёрстки.
- **Отзывов на сайте нет намеренно.** Прежние были выдуманы и сняты;
  блок собирается из `reviews.json` и появится, когда придут настоящие
  с указанием источника. Не выдумывать отзывы, цифры и регалии заново.
- **Секреты не коммитим.** Токен Telegram, доступы CRM и FTP — только
  в `api/config.php` на хостинге и в секретах GitHub.
- **Без внешних зависимостей.** Сайт остаётся статикой без фреймворков
  и обращений к сторонним CDN, шрифты — локальные.
- **Контраст и размеры целей.** Мелкий текст — не ниже 4.5 к фону, кнопки
  и ссылки — от 44 px. На этом сайт спотыкался до редизайна, проверки
  в `npm run check` это стерегут.

## Проверки

`npm run check` поднимает собранный сайт в headless-браузере (42 сценария:
каталог, фильтры, квиз, формы, меню, разметка, шрифты, отправка заявки).
Нужен Playwright; путь к пакету и браузеру можно передать через `PW_MODULE`
и `PW_CHROME`.

## Боевой домен

`karkascomfort.ru` пока не обновляется автоматически: секреты FTP
в репозитории не заданы, а из этой среды ни FTP, ни домен недоступны.
Варианты выгрузки — в `DEPLOY.md`.
