# Каркас Комфорт — редизайн сайта

Статический сайт (HTML + CSS + JS, без фреймворков и сборщиков-монстров).
Готовые страницы лежат в корне репозитория — их можно просто залить на хостинг по FTP.

## Быстрый старт

```bash
npm run build     # генерация иллюстраций + сборка страниц
npm run serve     # локальный просмотр на http://localhost:8080
```

Node.js нужен только для сборки. Итоговый сайт — обычная статика, никакого бэкенда для показа не требуется.

## Структура

```
index.html, proekty.html, ...   ← собранные страницы (коммитятся, их и заливаем на хостинг)
assets/
  css/style.css                 ← вся вёрстка и дизайн-токены
  js/main.js                    ← меню, фильтры, калькулятор, формы
  js/projects-data.js           ← сгенерирован из src/data/projects.json, руками не править
  img/projects/*.svg            ← иллюстрации каталога (заглушки под реальные фото)
src/
  partials/                     ← общие head, шапка, подвал, блок заявки
  pages/                        ← содержимое страниц (правим здесь!)
  data/projects.json            ← каталог проектов
tools/
  build.mjs                     ← сборка страниц + sitemap.xml
  gen-images.mjs                ← генерация иллюстраций каталога
```

**Важно:** страницы в корне перезаписываются при сборке. Правьте `src/pages/*.html`
и `src/partials/*.html`, затем запускайте `npm run build`.

## 1. Фирменные цвета

Вся палитра — в одном блоке в начале `assets/css/style.css`:

```css
:root {
  --brand:        #1F5C3A;   /* основной зелёный */
  --brand-deep:   #164429;   /* тёмные поверхности: топбар, подвал, блок заявки */
  --accent:       #C8791F;   /* тёплое дерево: цены, акцентные кнопки */
  ...
}
```

Замените значения на фирменные — они автоматически применятся ко всем страницам,
кнопкам, иконкам и подложкам. Ниже в файле есть такой же блок для тёмной темы
(`prefers-color-scheme: dark`) — если тёмная тема не нужна, этот блок можно удалить целиком.

Цвета иллюстраций каталога задаются отдельно, в объекте `P` в `tools/gen-images.mjs`
(после правки — `npm run images`).

## 2. Реальные фотографии вместо иллюстраций

Иллюстрации — временные заглушки, потому что доступа к фотографиям с текущего сайта не было.
Чтобы поставить фото:

1. Положите файлы в `assets/img/projects/` с именами из `slug` (например `kd-29.webp`).
2. В `assets/js/main.js` и `tools/build.mjs` замените расширение `.svg` на нужное
   (три места: карточка каталога, карточка похожих проектов, изображение на странице проекта).
3. Замените изображения в героях страниц (`src/pages/index.html`, `karkasnye-doma.html`).

Рекомендуемый размер карточки — 800×460, формат `.webp`.

## 3. Каталог проектов

Всё лежит в `src/data/projects.json`. Поля:

| Поле | Значение |
|---|---|
| `code`, `slug` | код проекта и имя файла картинки |
| `size`, `area`, `floors`, `bedrooms`, `terrace` | характеристики для фильтров и карточек |
| `tags`, `note` | метки и короткое описание |

После правки — `npm run build`.

**Цены в карточках сейчас считаются формулой** «площадь × 32 000 ₽» (ставка взята из
публичных материалов компании) и подписаны как ориентировочные. Перед публикацией
подставьте реальные цены: добавьте в JSON поле `price` и используйте его в
`tools/build.mjs` и `assets/js/main.js` вместо `p.area * 32000`.

## 4. Формы заявок

Сейчас формы проверяют данные и показывают подтверждение, но никуда не отправляют.
Чтобы подключить приём заявок, укажите адрес обработчика в теге `<body>`:

```html
<body data-lead-endpoint="/api/lead">
```

Функция `sendLead()` в `assets/js/main.js` отправит туда JSON вида
`{ name, phone, message, project, consent, page }`. Подойдёт любой PHP-скрипт,
serverless-функция или вебхук CRM.

## 5. Что стоит проверить перед публикацией

- [ ] Телефоны и почта в `src/partials/header.html`, `src/partials/footer.html`, `src/pages/kontakty.html`
      (в открытых источниках встречались разные номера: 8 (920) 171-69-69, 8 (4822) 75-25-05, +7 (930) 166-07-20)
- [ ] Номер офиса в адресе (в разных источниках — офис 31 и офис 37)
- [ ] Реальные цены и сроки в комплектациях и калькуляторе (`src/pages/index.html`, `assets/js/main.js`)
- [ ] Тексты отзывов — сейчас это заготовки, замените на настоящие
- [ ] Политика конфиденциальности — согласовать с юристом
- [ ] Счётчики Яндекс.Метрики / Google Analytics — добавить в `src/partials/head.html`
