# Каркас Комфорт — сайт компании

Статический сайт (HTML + CSS + JS, без фреймворков). Сборка кладёт готовый сайт
в папку `dist/` — её содержимое и заливается на хостинг.

Дизайн: «скандинавский люкс» — тёплая кремовая палитра, фирменный зелёный и цвет дерева,
полноэкранный первый экран, крупная типографика Onest + Golos Text.

**Перенос на домен и хостинг — в [DEPLOY.md](DEPLOY.md).**

## Быстрый старт

```bash
npm install       # один раз
npm run build     # собрать сайт в папку dist/
npm run serve     # посмотреть локально: http://localhost:8080
npm run pack      # архив для загрузки через панель хостинга
npm run deploy    # сборка + выгрузка по FTP (доступы в .env)
```

Node.js нужен только для сборки. На хостинг уезжает содержимое `dist/` — обычная
статика плюс один PHP-файл для приёма заявок.

## Структура

```
dist/                    ← результат сборки: это и заливаем на хостинг
assets/
  css/style.css          ← вся вёрстка и дизайн-токены
  fonts/*.woff2          ← Onest и Golos Text, self-hosted (кириллица + латиница)
  js/main.js             ← меню, фильтры, калькулятор, слои стены, формы
  js/projects-data.js    ← генерируется из src/data/projects.json, руками не править
  img/hero.svg           ← кадр первого экрана
  img/projects/*.svg     ← иллюстрации каталога (заглушки под реальные фото)
src/
  partials/              ← общие head, шапка, подвал, блок заявки
  pages/                 ← содержимое страниц (правим здесь!)
  data/projects.json     ← каталог проектов
  data/cases.json        ← построенные объекты для блока портфолио
server/
  .htaccess              ← настройки Apache: https, редиректы, кеш, сжатие
  nginx.conf.example     ← то же самое для nginx
  api/lead.php           ← приём заявок с форм
  api/config.php         ← куда слать заявки (правится на хостинге)
tools/
  build.mjs              ← сборка страниц + sitemap.xml
  gen-art.mjs            ← генерация иллюстраций
  gen-icons.mjs          ← favicon и иконки для телефонов
  deploy-ftp.mjs         ← выгрузка dist на хостинг
```

**Важно:** папка `dist/` перезаписывается при каждой сборке. Правьте `src/pages/*.html`,
`src/partials/*.html` и данные в `src/data/`, затем запускайте `npm run build`.

## 1. Фирменные цвета

Палитра — в одном блоке в начале `assets/css/style.css`:

```css
:root {
  --brand:      #1F5C3A;   /* основной зелёный */
  --brand-deep: #14301F;   /* тёмные поверхности: топбар, подвал, блок заявки, технология */
  --accent:     #C08A4A;   /* тёплое дерево: акценты, нумерация, кнопка заявки */
  --page:       #FBF8F2;   /* кремовый фон страницы */
  --page-2:     #F4EEE4;   /* второй тон для чередования секций */
  ...
}
```

Замените значения на фирменные — они применятся ко всем страницам. Ниже в файле
такой же блок для тёмной темы (`prefers-color-scheme: dark`); если она не нужна,
блок можно удалить целиком.

Цвета иллюстраций задаются отдельно — объект `C` в `tools/gen-art.mjs`
(после правки `npm run build`).

## 2. Шрифты

Onest (заголовки) и Golos Text (текст) подключены локально из `assets/fonts` —
без обращения к Google Fonts. Файлы взяты из пакетов `@fontsource-variable/*`
и скопированы командой:

```bash
npm i -D @fontsource-variable/onest @fontsource-variable/golos-text
cp node_modules/@fontsource-variable/onest/files/onest-{cyrillic,latin}-wght-normal.woff2 assets/fonts/
cp node_modules/@fontsource-variable/golos-text/files/golos-text-{cyrillic,latin}-wght-normal.woff2 assets/fonts/
```

Чтобы сменить шрифт — положите новые `.woff2` в `assets/fonts`, поправьте
`@font-face` и переменные `--display` / `--text` в начале `style.css`.

## 3. Реальные фотографии вместо иллюстраций

Иллюстрации — временные заглушки: доступа к фотографиям с текущего сайта не было.
Чтобы поставить фото:

1. Положите файлы в `assets/img/projects/` с именами из `slug` (например `kd-29.webp`),
   рекомендуемый размер 1600×1000.
2. Замените расширение `.svg` на нужное в трёх местах: `tools/build.mjs` (функции
   `projectCard` и `caseTile`) и `assets/js/main.js` (карточки каталога, похожие
   проекты, изображение на странице проекта).
3. Кадр первого экрана — `assets/img/hero.svg`; замените на широкое фото (2400×1350)
   и поправьте `src` в `src/pages/index.html`.

## 4. Каталог и портфолио

`src/data/projects.json` — каталог (код, размер, площадь, этажность, спальни, терраса).
`src/data/cases.json` — построенные объекты для блока портфолио: заголовок, срок,
комплектация и класс плитки в бенто-сетке (`tile--xl`, `tile--m`, `tile--w`).

**Цены сейчас считаются формулой** «площадь × 32 000 ₽» (ставка из публичных материалов
компании) и подписаны как ориентировочные. Перед публикацией добавьте в JSON поле `price`
и используйте его в `tools/build.mjs` и `assets/js/main.js` вместо `p.area * 32000`.

## 5. Формы заявок

Формы проверяют данные и показывают подтверждение, но никуда не отправляют.
Чтобы подключить приём заявок, укажите адрес обработчика в теге `<body>`:

```html
<body data-lead-endpoint="/api/lead">
```

Функция `sendLead()` в `assets/js/main.js` отправит туда JSON
`{ name, phone, message, project, consent, page }`. Подойдёт PHP-скрипт,
serverless-функция или вебхук CRM.

## 6. Что проверить перед публикацией

- [ ] Телефоны и почта в `src/partials/header.html`, `footer.html`, `src/pages/kontakty.html`
      (в открытых источниках встречались 8 (920) 171-69-69, 8 (4822) 75-25-05, +7 (930) 166-07-20)
- [ ] Номер офиса в адресе (в источниках — офис 31 и офис 37)
- [ ] Реальные цены комплектаций и ставки в калькуляторе (`src/pages/index.html`, `assets/js/main.js`)
- [ ] Тексты отзывов и карточки объектов в `cases.json` — сейчас это заготовки
- [ ] Политика конфиденциальности — согласовать с юристом
- [ ] Счётчики Яндекс.Метрики / Google Analytics — добавить в `src/partials/head.html`

## Проверено

Автотесты в headless Chromium (25 проверок): фильтры и сортировка каталога, страница
проекта по `?id=`, калькулятор, маска телефона, валидация и отправка форм, интерактивные
слои стены и их подсветка на разрезе, мобильное меню, отсутствие горизонтальной прокрутки
на 390 px, доступность всех внутренних ссылок на 10 страницах, загрузка шрифтов,
светлая и тёмная темы, а также реальная отправка заявки на PHP-обработчик
(валидация, отказ без согласия, ловушка для ботов, ответ 405 на GET).
