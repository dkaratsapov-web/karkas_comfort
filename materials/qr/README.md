# QR-код на каркаскомфорт.рф

Ведёт на `https://каркаскомфорт.рф/` (в коде записан punycode
`https://xn--80aa2abbmnbmggrx.xn--p1ai/` — так открывает любой сканер,
а в адресной строке браузер показывает кириллический домен).

| Файл | Для чего |
|---|---|
| `qr-karkascomfort.svg` | Вектор для печати: визитки, баннеры, наклейки. Масштабируется без потерь. |
| `qr-karkascomfort.png` | 1200×1200 для мессенджеров и презентаций. |
| `qr-karkascomfort-on-dark.svg/.png` | Инверсия для тёмных макетов. |
| `qr-karkascomfort-card.png` | Готовая плашка 1200×1600: логотип, код, домен и телефоны. |

Коррекция ошибок — уровень H (30 %), поэтому знак в центре не мешает
считыванию: код проверен декодером вплоть до размера 200×200 px.
Минимальный размер при печати — 20 мм по стороне кода, вокруг оставляйте
светлое поле не меньше четырёх модулей (в файлах оно уже есть).

Пересобрать после смены домена или знака:

```bash
npm i --no-save qrcode sharp
node tools/qr.mjs materials/qr
```

Адрес скрипт берёт из `src/data/site.json` (поле `domain`), знак — из
`assets/img/favicon.svg`. Плашку `-card.png` собирали отдельно из HTML,
её после смены домена нужно перерисовать вручную.
