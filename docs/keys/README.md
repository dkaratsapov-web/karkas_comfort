# Кейс «Каркас Комфорт» для сайта агентства

- `keys-karkas-komfort.md` — текст кейса (для переноса на сайт).
- `keys-karkas-komfort.html` — то же страницей, открывается в браузере.
- `screens/` — снимки: `desktop/` (1440 px), `mobile/` (390 px, плотность 2), `admin/` (демо-данные).
- `scripts/shots.mjs` — переснять снимки (`npm run build`, затем `node docs/keys/scripts/shots.mjs`; нужен php), `scripts/md2html.mjs` — собрать HTML из текста.

Цифр по результатам рекламы в кейсе нет: их нужно взять у заказчика или из кабинетов.
