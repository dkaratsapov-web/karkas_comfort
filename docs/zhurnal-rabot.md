## Как выкладывать

```bash
npm run build && npm run verify
git add -A && git commit -m "…"
npm run publish:site
```

`publish:site` сам собирает и проверяет; если проверка уже прошла на тех же
файлах, можно пушить без повтора: `node tools/publish.mjs`. После пуша на
GitHub идёт «Проверка сайта» (четыре параллельных задания, около 4 минут),
затем «Deploy to VPS» (около 4 минут). От пуша до сайта — около 8 минут.

В облачной среде Playwright подключается так (пакет лежит глобально):

```bash
export PW_MODULE=/opt/node22/lib/node_modules/playwright/index.mjs
export PW_CHROME=/opt/pw-browsers/chromium   # путь меняется между контейнерами; без PW_CHROME Playwright найдёт браузер сам
```

Из облачной среды закрыты российские сайты (справка Авито, eLama и т. п.)
и сам боевой домен. Открыть их можно в настройках среды: меню среды
в заголовке сессии → Edit → Network access (полный доступ или нужные
домены в Allowed domains). Изнутри сессии сервис настроек правку
отклонял.

Временная папка сессии (scratchpad) и всё вне git пропадают при
перезапуске контейнера. Результаты работы — только в репозиторий.

## Что сделано (кратко, по месяцам)

**Сентябрь.** Редизайн с нуля: дизайн-система «Чертёж» (холодная
чертёжная бумага, графит, золото знака, размерная линия вместо
надзаголовка, шрифт Onest). Весь сайт по новой системе, каталог
проектов, страницы объектов, видео, QR-код.

**Октябрь.** Боевой домен каркаскомфорт.рф, автовыгрузка на VPS
(настройка сервера одной командой, nginx, сертификат с автопродлением).
Слайдер первого экрана на фото объектов. Админка: заявки, CRM под
каркасное строительство, настройки приёма заявок, правка текстов
коммитом в репозиторий. 40 статей с перелинковкой. Поисковая проверка.

**Ноябрь.**
- Приём заявок: почта (SMTP), Telegram-уведомления, бот MAX с кнопками,
  вебхук CRM; страница «Спасибо»; в заявке видно источник.
- Интерактивная карта охвата на React: Тверская область и города
  Подмосковья, форма прямо в карточке города (без промежуточной кнопки).
- Мобильная версия: ленты со свайпом, круглые кнопки звонка и MAX,
  первый экран (фото во всю ширину, цифры списком), видео по одному
  на экран с кнопками, таблица комплектаций под кнопкой.
- Водяной знак на фото объектов и листах проектов при сборке.
- Юридические документы: политика, согласие на обработку ПД,
  политика cookie и баннер; Метрика только после согласия.
- Иллюстрации к блокам через Higgsfield.
- Агент проверки мобильной версии и агент-маркетолог.
- Проверки: многопоточная визуальная (3 мин вместо 10 локально),
  CI в четыре параллельных задания с кешем водяных знаков.
- «Кайзер»: тёплый контур от 3 840 000 ₽ (поле `priceFrom`), цена
  проекта двумя ступенями — контур строкой, «под ключ» плашкой.
- «Колесниково»: четыре визуализации от заказчика.
- Telegram убран с сайта (ссылки нет). Уведомления о заявках
  в Telegram на сервере остались — это внутренний канал.
- «Более 300 домов» без «бань и хозпостроек»; ипотека без ставки
  «от 5 %» (без банка и условий нельзя по закону о рекламе).
- Кнопка в заголовке блока у правого края; кадр в окне просмотра по
  центру — проверено обходом всех 69 страниц.

## Решения заказчика

- Отзывов на сайте нет, пока не придут настоящие с источником.
- Telegram на сайте не показываем, пока нет ссылки.
- Из маркетингового аудита сделаны пункты 1 (Telegram), 6 («300+
  домов»), 7 (ипотека). Остальное отложено до согласования.
- Ничего из аудита не внедрять без согласования.

## Открытые вопросы к заказчику

- Реальная цена «под ключ» для «Кайзера». Сейчас она расчётная:
  56 м² × 80 000 ₽ = 4 480 000 ₽.
- Площадь, срок и комплектация объектов № 1, 2, 3, 6; место для № 6.
- Почему у «Ходаковой» (77 м²) и «Павлинова» (105 м²) одна цена 6,5 млн.
- Почему объект в Олбово 140 м², а проект «Олбово» 152 м².
- Банк и программа для ипотеки, если хотим вернуть ставку.
- Сколько построено именно домов; как писать «с 2009 года» при
  регистрации ООО в 2020 году.
- Обезличенные образцы договора и сметы (без закупочных цен).
- Кто ведущие в роликах и на каких объектах сняты ролики.
- Названия проектов «Ходакова», «Павлинов», «Ласточкин» — не фамилии
  ли клиентов (нужно согласие).
- Отдельные номера под каналы рекламы, если нужен коллтрекинг.
- Уведомление в Роскомнадзор об обработке ПД; сервер в России;
  передача данных за рубеж (ipwho.is, Telegram).
- Смена пароля временной учётки в админке, токен GitHub для правки
  текстов, SMTP.
