# Креативы для Авито Рекламы

Версия 2 (20.11.2026). Картинки — в `kreativy/`, скрипты сборки —
в `scripts/`, исходники (вырезанные дома и отретушированные кадры) —
в `sources/`.

## Направления

- **«Лист»** — дом вырезан из настоящего фото и стоит на чертёжном листе
  с сеткой; золотые выноски с характеристиками и штамп, как на рабочем
  чертеже.
- **«Графит»** — тёмное поле с ритмом стоек каркаса, тёплый свет за
  домом, крупная цифра.
- **«Журнал»** — фото объекта в паспарту на бумаге, подпись как
  в архитектурном издании.

Каждая идея в пропорциях 1:1 (1080×1080), 4:3 (1200×900) и 3:4
(1200×1600), плюс баннеры на главную 1320×492 (8:3) и 2934×456 (13:2,
три дома в ряд).

## Требования Авито, которые соблюдены

По справке Авито Рекламы (ads-help.avito.com, собрано через поиск —
из облачной среды справка закрыта):

- нативный баннер: JPEG/PNG до 2 МБ; заголовок до 30, описание до 45
  символов; текст и логотип на картинке не больше 20 % площади
  (у наших 7–17 %); логотип 50×50 до 250 КБ (`kreativy/logo-50.png`);
- баннер на главной: 2934×456 (13:2) или 1320×492 (8:3), до 500 КБ,
  охранная зона 16 px, без QR; минимальный бюджет группы от 200 000 ₽;
- нельзя использовать бренд Авито (слово, логотип, цвета).

## Как сделаны и как пересобрать

1. Фото — настоящие кадры объектов с сайта (`assets/img/photos/`).
2. Higgsfield делал ретушь (`gpt_image_2_6`). Ретушь целиком не берём:
   нейросеть дорисовывала в окнах чужие отражения и перерисовывала
   кирпич. `scripts/grade.cjs` переносит с ретуши только кривую яркости,
   насыщенность и баланс белого на исходные пиксели.
3. Дома вырезаны моделью Higgsfield `image_background_remover` (режет
   по снимку, не перерисовывает). Вырезки — `sources/*-cut.png`.
4. Вёрстка — HTML шрифтом сайта Onest, рендер Playwright:
   `scripts/make2.mjs` (шаблоны) и `scripts/run2.mjs` (набор). Пути
   к папкам заданы в начале файлов — поменять под свою машину.
   ```bash
   export PW_MODULE=/opt/node22/lib/node_modules/playwright/index.mjs
   export PW_CHROME=/opt/pw-browsers/chromium   # путь меняется между контейнерами; без PW_CHROME Playwright найдёт браузер сам
   node docs/avito/scripts/run2.mjs
   ```
