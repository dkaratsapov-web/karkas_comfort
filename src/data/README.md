# Данные сайта

| Файл | Что внутри | Как заполнять |
|---|---|---|
| `projects.json` | 15 проектов каталога | `price` — реальная цена под ключ в рублях; пока `null`, цена «от» считается как площадь × базовая ставка «Тёплый контур» из `pricing.json` и подписывается «ориентировочно». `photos` — имена файлов из `assets/img/photos/`, первый кадр становится главным и попадает в og:image. `plan` — файл планировки. `term` — точный срок, если он известен. |
| `cases.json` | Построенные объекты для портфолио | `photos` — так же, как в проектах. |
| `pricing.json` | Ставки за м², фундамент, условия ипотеки | Меняется в одном месте — пересчитываются каталог, карточки, квиз и калькулятор. |
| `reviews.json` | Отзывы клиентов | **Пустой массив = блок отзывов на сайте не выводится.** Добавляйте только реальные отзывы: `{ "text": "…", "author": "Имя", "detail": "дом 118 м², Конаковский район", "source": "Яндекс.Карты", "url": "https://…" }`. Поля `source` и `url` показываются как ссылка на первоисточник. |

После правки данных: `npm run build`.
